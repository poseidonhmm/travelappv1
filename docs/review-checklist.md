# Review checklist

## Before a profile is published
- [ ] Correct place granularity, canonical label, country and Wikidata entity
- [ ] Verified coordinates / bounding area from geographic source
- [ ] Any experiences and food descriptions checked against reputable independent sources
- [ ] Editorial value judgments ("romantic", "posh", "sociable") reviewed as opinions, not universal facts
- [ ] Price levels defined with a methodology and a date; otherwise left unknown
- [ ] Best season supported by appropriate climate data; historical averages are not forecasts
- [ ] Broad regions split into smaller sub-destinations for activities, costs and weather where necessary
- [ ] Relevant sources logged with URLs, accessed dates and specific supported claims
- [ ] Licensed media only, with source/creator/usage rights/attribution recorded
- [ ] No invented hotels, transit times, itineraries or provider availability

## AI-assisted enrichment process
1. Research candidate facts and source URLs; do not populate unsourced objective data.
2. Generate a draft profile with specific atmosphere, scenery and experience descriptions.
3. Check statements against the linked material; record which claim each source supports.
4. Merge redundant tags and reject vague or promotional text.
5. Manually approve the record. Only approved records enter the public search index.
